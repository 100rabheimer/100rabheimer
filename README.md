- Added quota enforcement, cost calculation, and Stripe Checkout + webhooks
- Containerized with Docker Compose and PostgreSQL

**GitHub:** https://github.com/100rabheimer/MeterForge

### InvoiceIQ — AI-Powered Invoice Processing System
- Designed an end-to-end pipeline using Tesseract OCR + LayoutLM
- Extracted structured data (vendor, date, invoice number, total) from invoice images
- Combined FastAPI ML service with Express.js/MongoDB backend and React dashboard

**GitHub:** https://github.com/100rabheimer/InvoiceIQ
